# Специфікація проєкту: Календар менструального циклу

## 1. Загальний опис

Односторінковий веб-застосунок (SPA без бекенду) для відстеження менструального
циклу. Показує поточний цикл у вигляді сітки днів із кольоровим кодуванням фаз
циклу. Дані вводяться вручну користувачем і зберігаються локально в браузері.

## 2. Технічний стек

- HTML5
- CSS3 (без препроцесорів та CSS-фреймворків)
- Vanilla JavaScript (ES6+, без фреймворків та бандлерів)
- Без бекенду — статичний сайт
- Хостинг: GitHub Pages

## 3. Функціональні вимоги

### 3.1 Вхідні дані (вводяться вручну)

- **Дата початку останнього менструального циклу** — date picker.
- **Тривалість циклу** (кількість днів між початками двох послідовних
  менструацій) — числове поле, за замовчуванням 28.
- **Тривалість менструації** (кількість днів кровотечі) — числове поле, за
  замовчуванням 5.

### 3.2 Автоматичні розрахунки

- **Дні овуляції** обчислюються автоматично на основі дати початку циклу та
  його тривалості за формулою лютеїнової фази (~14 днів до наступної
  менструації):
  - День овуляції = дата початку циклу + (тривалість циклу − 14).
- **Фертильне вікно** = день овуляції ± 2 дні (5 днів включно з днем
  овуляції), підсвічується окремим (четвертим) кольором, відмінним від кольору
  дня овуляції.
- **Дні менструації** = дата початку циклу … дата початку циклу + (тривалість
  менструації − 1).
- **Наступний цикл** розраховується для продовження сітки за межі поточного
  циклу (дата початку + тривалість циклу).

### 3.3 Відображення (грід)

- Один екран (one-page application), без прокрутки між "сторінками".
- Візуалізація — сітка-календар (grid), де кожна клітинка = один календарний
  день, розташована по тижнях рядками (пн–нд у рядку), як у звичайному
  календарі. Дні, що не належать до відображуваного діапазону, але потрапляють
  у тиждень першого/останнього дня діапазону, показуються порожніми/неактивними
  клітинками для збереження цілісності сітки тижнів.
- Відображається поточний цикл повністю + 5 днів до дати початку циклу та 5
  днів після завершення циклу (дати початку наступного циклу мінус 1 день).
- У кожній клітинці: число місяця (і скорочена назва місяця на межі місяців,
  де змінюється місяць).
- Кольорове кодування типів днів (кожен колір кастомізований користувачем):
  1. **Дні менструації** — колір 1.
  2. **Дні овуляції** (день овуляції) — колір 2.
  3. **Дні фертильного вікна** (овуляція ± 2 дні, без урахування самого дня
     овуляції) — колір 3.
  4. **Звичайні дні циклу** (дні між менструацією та фертильним вікном — не є
     100% безпечними через життєздатність сперматозоїдів) — колір 4.
  5. **Безпечні дні** (від дня після завершення фертильного вікна до кінця
     циклу — запліднення неможливе, оскільки яйцеклітина вже загинула) —
     колір 5.
- **Сьогоднішній день** візуально виділяється додатково (наприклад, рамкою),
  незалежно від кольору фази.
- **Навігація по циклах**: користувач може гортати цикли вперед і назад
  (кнопки "попередній"/"наступний" або свайп по гріду на мобільних
  пристроях), при цьому грід перебудовується для обраного циклу за тією ж
  логікою (+5 днів до / +5 днів після). Є можливість швидко повернутися до
  поточного циклу (клік на підпис з датами циклу).
- **Деталі дня**: клік/тап на клітинку дня відкриває нижню панель (bottom
  sheet) з повною датою та назвою фази цього дня, а також кнопкою "Позначити
  початок циклу тут" — вона встановлює обраний день як нову дату початку
  циклу (наприклад, якщо менструація почалась раніше/пізніше передбаченого).

### 3.4 Кастомізація кольорів

- Користувач може змінити колір для кожної з п'яти категорій днів
  (менструація, овуляція, фертильне вікно, звичайні дні, безпечні дні) через
  color picker у налаштуваннях.
- Обрані кольори зберігаються разом з іншими даними.

### 3.5 Дефолтна палітра кольорів

Якщо користувач ще не кастомізував кольори, використовуються пастельні
кольори за замовчуванням:

| Категорія               | Колір            | HEX       |
| ------------------------ | ---------------- | --------- |
| Дні менструації           | пастельно-рожевий | `#F7C6D9` |
| Дні овуляції              | пастельно-фіолетовий | `#D9C6F7` |
| Дні фертильного вікна     | пастельно-блакитний | `#C6E2F7` |
| Звичайні дні циклу        | пастельно-жовтий  | `#FCEFC7` |
| Безпечні дні              | пастельно-зелений | `#C6F7D9` |

### 3.6 Збереження даних

- Усі введені дані (дата початку циклу, тривалість циклу, тривалість
  менструації, кастомні кольори) зберігаються в `localStorage` браузера.
- При повторному відкритті сторінки застосунок автоматично підвантажує
  збережені дані та рендерить актуальний стан гріда (з урахуванням поточної
  дати).
- Без збережених даних — показується форма первинного налаштування.

## 4. Нефункціональні вимоги

- Повна робота офлайн після першого завантаження (без зовнішніх залежностей
  та API).
- Адаптивність під мобільні екрани (мінімальна ширина — вужчий екран
  смартфона).
- Розгортання без build-кроку: чистий HTML/CSS/JS, сумісний з GitHub Pages
  "як є".

- PWA / інсталяція на пристрій.

## 7. Прийняті рішення

- Діапазон відображення: 5 днів до початку циклу + 5 днів після його
  завершення, окрім самого циклу.
- Фертильне вікно виділяється окремим (четвертим) кольором, відмінним від
  кольору дня овуляції.
- Сітка організована по тижнях, рядками, як у звичайному календарі (пн–нд).
